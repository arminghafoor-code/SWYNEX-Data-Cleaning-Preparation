# SWYNEX-Data-Cleaning-Preparation | Task 1
### Dataset: Telco Customer Churn

**Internship:** SWYNEX Data Analytics
**Tool Used:** Microsoft Excel

### Project Overview
This project is about cleaning and preparing raw Telco Customer Churn data for analysis.

### Data Cleaning Steps
1. Handled Missing Values in TotalCharges column
2. Removed Duplicate customerIDs using Excel
3. Converted TotalCharges from Text to Number format
4. Used TRIM() to remove extra spaces
5. Standardized columns like Churn, Gender

### Files
- Telco_Customer_Churn_Raw.csv (Original Data)
- Telco_Customer_Churn_Cleaned.xlsx (Final Cleaned Data)

### Outcome
Data is now 100% clean and ready for EDA and analysis.
